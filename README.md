# Sprint_6 - Автотесты сервиса "Яндекс.Самокат"

Задание проекта:
1. Проверить выпадающий список в разделе «Вопросы о важном». При нажатии на каждый вопрос открывается соответствующий ответ.
2. Проверка позитивного сценария заказа самоката с использованием разных кнопок "Заказать". Используются два разных набора тестовых данных. 
3. Проверка перехода на главную страницу «Самоката» при нажатии на лого "Самоката".
4. Проверка перехода на страницу "Дзен" при нажатии на лого "Яндекс".

## Структура проекта
├── allure_results/              # Allure отчеты о тестировании
├── tests/
│   ├── test_faq.py              # Тесты для раздела "Вопросы о важном"
│   └── test_scooter_order.py    # Тесты для создания заказа и проверки логотипов
├── pages/
│   ├── base_page.py             # Базовый класс Page Object
│   ├── main_page.py             # Главная страница
│   ├── order_page.py            # Страница оформления заказа
│   └── header.py                # Компонент шапки сайта
├── locators/
│   ├── main_page_locators.py    # Локаторы для главной страницы
│   ├── order_page_locators.py   # Локаторы для страницы заказа
│   └── header_locators.py       # Локаторы для шапки сайта
├── data.py                      # Тестовые данные (учетные данные, детали аренды, вопросы)
├── urls.py                      # URL тестируемых страниц
├── conftest.py                  # Фикстуры pytest
├── requirements.txt             # Зависимости проекта
├── .gitignore
